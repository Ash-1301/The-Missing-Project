# The Missing Project

A 3D first-person detective mystery game developed in Unity, where players investigate a suspicious disappearance by exploring environments, collecting clues, interacting with characters, and uncovering the truth through deduction.

## Overview

The Missing Project places the player in the role of an investigator tasked with solving a mysterious case. By examining evidence, questioning suspects, and piecing together information, players gradually reveal what happened and identify the culprit.

The project focuses on environmental storytelling, player-driven investigation, dialogue systems, and interactive clue collection.

## Features

- First-person 3D exploration
- Interactive evidence collection system
- Character dialogue and questioning
- Clue-based investigation mechanics
- Inventory system for collected evidence
- Story-driven mystery narrative
- Multiple locations to investigate
- Puzzle-solving and deduction gameplay

## Built With

- Unity 2022.3 LTS
- C#
- Unity Input System
- Unity UI System

## Gameplay

Players must:

1. Explore the crime scene.
2. Collect and inspect evidence.
3. Interview suspects and witnesses.
4. Connect clues together.
5. Determine the sequence of events.
6. Solve the mystery and identify the responsible individual.
